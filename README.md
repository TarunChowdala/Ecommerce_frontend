# 🛒 E-Commerce Platform

A full-featured **E-Commerce Platform** built with **React** and **Tailwind CSS** on the frontend, and **Node.js**, **Express.js**, and **SQLite** on the backend.  
Includes product listings, cart management, checkout process, and integrated Razorpay payment gateway.

---

## 🚀 Features
- **Product Listings** – Browse products with responsive UI.
- **Product Details Page** – View detailed information for each product.
- **Cart Functionality** – Add, remove, and update items in the cart.
- **Checkout Process** – Seamless order placement flow.
- **Payment Integration** – Razorpay payment gateway integration.
- **Responsive Design** – Optimized for all devices using Tailwind CSS.

---

## 🛠 Tech Stack

### **Frontend**
- React
- Tailwind CSS

### **Backend**
- Node.js
- Express.js
- SQLite

### **Payment Gateway**
- Razorpay

## 📦 Installation & Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/TarunChowdala/Ecommerce_frontend.git
   cd Ecommerce_frontend

2.  **Install dependencies:**
    Using npm:
    ```bash
    npm install
    ```
    Or using yarn:
    ```bash
    yarn install
    ```

### Running the Development Server

To start the development server with hot module replacement (HMR):
